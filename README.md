# SkillCraft Landing Page

A responsive landing page created as **Task 1** for the **SkillCraft Technology Web Development Internship**.

## Features

- Fixed Navigation Bar
- Navigation Color Change on Scroll
- Hover Effects on Navigation Links
- Responsive Design
- Hero Section
- About Section
- Services Section
- Contact Section
- Footer
- Smooth Scrolling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
task-01-responsive-landing-page/
│── index.html
│── style.css
│── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Or, if you're using VS Code, run it with the **Live Server** extension.
